# Mantar Çiftliği

Tarayıcıda oynanan mantar yetiştiriciliği simülasyonu. Gerçek üretim aşamalarını ve hedef değerlerini izler.

## Nasıl oynanır

`index.html` dosyasını bir tarayıcıda açın. Kurulum gerekmez; oyun kaldığınız yerden devam eder (tarayıcıda saklanır).

GitHub Pages ile yayınlamak için: **Settings → Pages → Branch: main / (root)**.

## Ürünler

### İstiridye mantarı (Pleurotus)
1. **Substrat:** talaş (kavak, kayın/meşe, çam), buğday kepeği, kireç, alçı ve su. Hedef: nem %60–66, kepek %15–22, pH 6,5–7,5.
2. **Sterilizasyon:** otoklav (121 °C, merkez ≥ 90 dk) veya buharlı pastörizasyon (65–80 °C, ≥ 8 saat).
3. **Misel ekimi:** torbalar 30 °C altına soğuyunca aşılama; kış, yaz ve sarı istiridye türleri.
4. **Kuluçka odası:** karanlıkta, torba içi 22–27 °C; yeşil küflü torbaları ayıklama.
5. **Üretim odası:** torba kesimi, günde 8–12 saat ışık, CO₂ < 1000 ppm, nem %85–95.
6. **Hasat:** kümeler kenarları kıvrıkken toplanır (A), düzleşince B, spor saçınca C. 3 flaş.

### Beyaz şapkalı mantar (Agaricus bisporus)
1. **Kompost (Faz I):** buğday sapı, tavuk gübresi, jips, su; yığını aktarma.
2. **Pastörizasyon (Faz II):** 58–60 °C'de 8 saat, sonra 45–48 °C'de amonyak < 10 ppm.
3. **Misel ekimi**, 4. **Kuluçka odası**, 5. **Üretim odası** (örtü toprağı, şoklama), 6. **Hasat**.

Her partinin sonunda satış raporu, biyolojik verim ve iyileştirme önerileri gösterilir; kazançla çiftliğe yatırım yapılabilir.
